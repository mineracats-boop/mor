                              CONDICIONES

                              Cómo bloquear el móvil de verdad (fijar Mor)

                              Una web no puede bloquear las demás apps por sí sola, pero tu móvil sí:

                              Android: Ajustes › Seguridad (o «Seguridad y privacidad» › Más ajustes) › Fijar aplicaciones › actívalo. Luego abre Mor, pulsa el botón de apps recientes (el cuadrado o desliza desde abajo y espera), toca el icono de Mor arriba y elige Fijar. Para soltarlo hay que mantener Atrás + Recientes (o deslizar y mantener).

                              iPhone: Ajustes › Accesibilidad › Acceso guiado › actívalo y pon un código. En Mor, pulsa 3 veces el botón lateral › Iniciar.

                              🔔 AVISOS CON MOR CERRADO

                              Para que el móvil te avise de recordatorios y de tu rutina aunque Mor esté cerrado, hace falta un pequeño servidor tuyo, gratis, en Cloudflare. Solo guarda las horas de los avisos (nunca el texto) y gasta unas 1.440 de las 100.000 ejecuciones gratis al día: no afecta a tus juegos.
                              Montarlo (una vez, 5 minutos)

                              1. dash.cloudflare.com › Workers & Pages › Create › Start with Hello World! › nombre mor-avisos › Deploy.

                              2. Edit code › borra todo › pega el código › Deploy.

                              3. Storage & databases › Workers KV › Create › nombre mor-avisos. Vuelve al Worker › Settings › Bindings › Add › KV namespace › nombre de variable AVISOS › elige mor-avisos.

                              4. Worker › Settings › Trigger events › Add › Cron trigger › cada minuto (* * * * *).

                              5. Copia la dirección del Worker (https://mor-avisos.…workers.dev) y pégala aquí.

                              En iPhone solo funciona con Mor instalado en la pantalla de inicio (iOS 16.4 o más).
