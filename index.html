                        CEREBRO LOCAL (OLLAMA)

                        Una IA que funciona en vuestro propio ordenador: sin límites y gratis. Mor la usa para el agente de código y para crear juegos (y, si quieres, también para el chat). Solo funciona en el ordenador donde está instalada y con él encendido; si no responde, Mor sigue con Gemini.
                        1. Instala Ollama desde ollama.com/download (Windows, Mac o Linux) y ábrelo.
                        2. Descarga un modelo para programar. Abre la terminal (en Windows: tecla Windows, escribe cmd) y escribe el que vaya con tu ordenador:
                          Tarjeta gráfica de 8 GB o 16 GB de RAM:ollama pull qwen2.5-coder:7b
                          Gráfica de 12–16 GB:ollama pull qwen2.5-coder:14b
                          Gráfica de 24 GB o Mac con 32 GB o más:ollama pull qwen3-coder:30b
                          Cuanto más grande, más listo pero más lento. Tarda un rato en descargarse (de 5 a 20 GB).
                        3. Deja que Mor hable con Ollama (una sola vez). En la misma terminal:
                          Windows:setx OLLAMA_ORIGINS ""
                          Mac:launchctl setenv OLLAMA_ORIGINS ""
                          Después cierra Ollama (icono junto al reloj › Quit) y vuelve a abrirlo. Si Chrome pregunta si esta web puede acceder a dispositivos de tu red local, pulsa Permitir.
                        4. Conéctalo aquí:
                        5. Usarlo también desde el móvil (opcional). En el ordenador, instala cloudflared (Windows: winget install Cloudflare.cloudflared · Mac: brew install cloudflared) y deja abierta una terminal con:
                          Abre un túnel seguro (https) hacia tu Ollama:cloudflared tunnel --url http://localhost:11434 --http-host-header="localhost:11434"
                          Saldrá una dirección como https://algo-algo.trycloudflare.com. Pégala aquí y guarda: se copia sola al móvil con la sincronización. No gasta nada de vuestra cuenta de Cloudflare (ni hace falta cuenta). La dirección cambia cada vez que abres el túnel, y mientras esté abierto cualquiera que la conozca podría usar vuestro Ollama: no la compartas y cierra la terminal cuando no lo uses.

                        CEREBROS GRATIS

                        Una llave gratuita de cada servicio: cuantas más pongáis, más difícil es que Mor se quede sin cerebro. Groq y Cerebras son los más rápidos y Mor los usa primero para las respuestas del chat; el resto, de respaldo. Para programar va primero vuestro cerebro local (Ollama). Cada llave la crea el dueño de la cuenta en la web del servicio (enlace «Conseguir llave»); pégala y pulsa Probar. Se guardan solo en vuestros aparatos y viajan cifradas con la sincronización.

                        SINCRONIZAR Y COPIA DE SEGURIDAD

                        Mor guarda su memoria, tus chats, rutina, proyectos, skills y llaves en un repo privado de tu GitHub («mor-datos»), cifrado con tu contraseña: nadie más puede leerlo, ni GitHub. Así eres el mismo Mor en el móvil y en el ordenador, y si se borra el navegador no pierdes nada.
                        Usa la misma contraseña en todos tus aparatos (la de entrar a Mor). Necesita tu token de GitHub en Conectores.

                        AVISOS CON MOR CERRADO

                        Para que el móvil te avise de recordatorios y de tu rutina aunque Mor esté cerrado, hace falta un pequeño servidor tuyo, gratis, en Cloudflare. Solo guarda las horas de los avisos (nunca el texto) y gasta unas 1.440 de las 100.000 ejecuciones gratis al día: no afecta a tus juegos.
                        Montarlo (una vez, 5 minutos)

                        1. dash.cloudflare.com › Workers & Pages › Create › Start with Hello World! › nombre mor-avisos › Deploy.

                        2. Edit code › borra todo › pega el código › Deploy.

                        3. Storage & databases › Workers KV › Create › nombre mor-avisos. Vuelve al Worker › Settings › Bindings › Add › KV namespace › nombre de variable AVISOS › elige mor-avisos.

                        4. Worker › Settings › Trigger events › Add › Cron trigger › cada minuto (* * * * *).

                        5. Copia la dirección del Worker (https://mor-avisos.…workers.dev) y pégala aquí.

                        En iPhone solo funciona con Mor instalado en la pantalla de inicio (iOS 16.4 o más).
