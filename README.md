# M.O.R.

Compañero digital de estudio de Rocket Jam: dos ojos celestes que viven en tu dispositivo, hablan contigo, te ayudan a estudiar y lo recuerdan todo.

- App web instalable (PWA), sin servidor: funciona en el navegador y habla directamente con Gemini y las voces.
- Las claves **no** están en el código: se dan una vez por dispositivo con el enlace de configuración privado.
- La memoria se guarda en cada dispositivo (copia de seguridad en *Más → Memoria*).
